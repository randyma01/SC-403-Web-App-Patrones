Práctica #2 - Catálogo y Consultas Avanzadas

Implementación integral de Consultas Ampliadas, Consultas JPQL y Consultas SQL Nativas sobre el catálogo de Árboles de Costa Rica, desarrollado con Spring Boot, Spring Data JPA, Hibernate, MySQL y Thymeleaf bajo arquitectura MVC.
